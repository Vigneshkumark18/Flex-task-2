# Flex Task 2

## 📌 About the Project

Flex Task 2 is a front-end web development project created using HTML5 and CSS3. This project focuses on practicing CSS Flexbox properties 
to create structured layouts, align elements, and manage spacing between webpage components. It helped me improve my understanding of 
flexible layouts and CSS positioning techniques.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox

## ✨ Features

* Flexible webpage layout
* Element alignment and spacing
* Organized content structure
* Practice with Flexbox properties
* Simple and clean design

## 🎯 Purpose

The main purpose of this project is to strengthen my CSS Flexbox skills and gain practical experience in building structured web layouts.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in your web browser.
